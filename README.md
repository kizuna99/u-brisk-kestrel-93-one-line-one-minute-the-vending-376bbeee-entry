A single vending-machine pickup line, written by `main.ts` to `/output/entry.txt`:

> I hum at strangers all day, but for you I'd drop everything — literally, from coil C4.

## Why this line

Picked by a 16-candidate head-to-head tournament against the published judge
criteria, in order: spoken by the machine itself to a passing human; built from
the machine's own world (its hum, its drop, its coil C4); the laugh turns
literal in the last words ("drop everything — literally, from coil C4"); short
enough to read in one breath; and charming rather than creepy.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output npx tsx main.ts   # or any TS runner / ts-node
cat /output/entry.txt
```
